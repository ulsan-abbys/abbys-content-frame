# 병원 원장 블로그 작업실 (가상 예시)

## 나
- 울산에서 동네 피부과를 운영하는 개원의 (가상 인물 — 시연용)
- 블로그 목적: 환자가 진료 전에 알면 좋은 **건강 정보**를 쉽게 전한다. 홍보 글이 아니다.

## 일하는 방식
1. 시작하면 STATE.md를 읽고 "지금 하는 일"부터 이어간다.
2. 글은 `초안/`에, 쇼츠 대본은 `대본/`에 저장한다.
3. 끝나면 아래 "의료법 점검표"를 한 줄씩 대조한 결과를 글 맨 아래에 붙인다.
4. STATE.md의 "지금 하는 일 / 다음에 할 일"을 고친다.

## 끝 기준
- 본문 1500자 안팎, 소제목 3개, 공신력 있는 출처 2개 이상 (질병관리청·대한피부과학회·국가건강정보포털 등)
- [원장 경험] 칸 2개를 비워 둔다 — 사람이 채운다. AI가 지어내지 않는다.
- 쇼츠 대본: 45초(약 230자), 문장마다 줄바꿈

## 의료법 점검표 (의료법 제56조 — 하나라도 걸리면 고친다)
- 순수 건강 정보로 쓴다. 우리 병원 시술·가격·이벤트·예약 안내를 넣지 않는다 (넣으면 의료광고 → 사전심의 대상)
- 환자 치료 후기·경험담·전후 사진을 쓰지 않는다 (제2호)
- "완치", "100%", "최고", "부작용 없음" 같은 효과 보장·과장 표현 금지 (제3호·제8호)
- 다른 병원·다른 시술과 비교하거나 깎아내리지 않는다 (제4호·제5호)
- 위험 신호가 있으면 "진료를 받으세요"로 끝낸다. 진단·처방을 글로 대신하지 않는다
- 근거 없는 수치를 쓰지 않는다. 수치는 출처와 함께만

## 말투
- 존댓말, 진료실에서 환자에게 설명하듯 쉬운 말
- "~하는 것이 중요합니다" 같은 AI 상투 문장, 이모지, 해시태그 나열 금지
- 표는 꼭 필요할 때 1개까지

## 하지 말 것
- 자동 게시 안 함. 게시 버튼은 원장이 직접 누른다.
- 출처 URL을 지어내지 않는다. 확인 못 한 링크는 "[확인 필요]"로 적는다.
