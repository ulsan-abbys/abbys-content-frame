이 저장소의 AGENTS.md를 먼저 읽고, "Codex 실행 순서 (블로그)"에 따라 내 네이버 블로그 글 한 편을 임시저장까지 도와줘.

저장소 루트에서 uv run frame setup doctor부터 실행해. Git·uv·Codex CLI 준비가 부족하면 필요한 설치와 내가 직접 할 로그인만 안내해 줘. 기존 설정·작업폴더가 있으면 재사용하고 분야·지역·독자·검색어·말투 등 아직 모르는 정보만 질문해. 대화에서 받은 주제 답은 setup topics --from-json으로 저장해도 돼. API 키는 선택 사항이고 비밀 값은 대화나 파일에 적지 마.

선택적으로 RSS와 사용 가능한 NAVER API HUB 키로 조사하고, G1에서 후보와 이유를 보여 준 뒤 내가 주제를 고를 때까지 기다려. 선택 후 작업폴더 준비 → --engine codex로 초안 작성 → check 순서로 진행해. G2에서 내 실제 경험과 사실·출처 검수를 기다리고 경험을 지어내지 마.

검수가 끝나면 naver draft로 준비물을 만들고 로컬 HTTP 서버로 열어 줘. 생성된 .agent.txt의 file:// 주소를 서버 주소로 바꿔서 내가 Codex에 연결한 브라우저 도구로 지시서를 실행해. 연결된 도구와 기능을 확인하고 기존 로그인 세션만 사용해. 로그인·캡차·보호조치·명시적 차단이 나오면 즉시 중단하고 알려 줘. 우회나 로그인 자동화 코드를 만들지 마.

기본 목표는 임시저장이야. G3에서 내가 이 글과 대상 블로그의 공개 발행을 명시 승인한 경우에만 발행해. 이미 승인했다면 반복해서 묻지 마. 미작성 경험 슬롯이나 확인 필요 문구가 남으면 발행하지 마. 임시저장은 실제 저장 상태·제목·본문과 편집기 URL을, 발행은 실제 게시물 URL·제목·본문·출처 링크를 확인해 보고해. 확인할 수 없으면 완료라고 말하지 마. 커밋·푸시는 하지 마.
