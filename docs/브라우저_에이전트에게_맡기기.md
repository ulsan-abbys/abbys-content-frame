# 브라우저 에이전트에게 초안 옮기기 맡기기

Claude in Chrome, ChatGPT @Chrome, Aside에서 사용자가 실행하는 절차입니다. 저장소는 로컬 HTML만 만들며 브라우저 조작 코드를 제공하지 않습니다. 사용하는 도구가 로컬 파일 열기, 버튼 클릭, Ctrl+V와 편집기 서식 확인을 지원해야 합니다.

> **경고 — 기본 권장은 사람이 직접 붙여넣기입니다.**
> 네이버 이용약관은 자동화 수단에 의한 게시물·콘텐츠 삽입을 금지한다 — 실제 네이버 블로그에 에이전트로 붙여넣는 것은 계정 제재 위험이 있으며 사용자 본인의 판단이다.
> 이 문서는 네이버의 허용이나 계정 안전을 보장하지 않습니다. 발행은 항상 사람이 합니다.

먼저 `uv run frame naver draft 작업실/초안/글.md`를 실행합니다. 출력된 `.naver.html`의 절대 경로와 대상 편집기를 아래 프롬프트에 넣으세요. 이미 로그인한 사용자 브라우저 프로필에서만 진행합니다. 새 프로필을 만들거나 로그인 정보를 전달하지 마세요.

## 에이전트에게 복사해서 줄 프롬프트

```text
초안 HTML: [여기에 .naver.html의 절대 경로]
대상 편집기: [사용자가 이미 열어 둔 편집기 탭]

사용자가 이미 로그인한 브라우저 프로필만 사용해 초안을 옮겨 줘.
CAPTCHA/캡차, 보호조치 또는 로그인 화면이 나오면 즉시 중단하고 알려 줘.
대신 로그인하거나 자동으로 재시도하지 마. 우회나 다른 프로필 사용도 금지야.

1. .naver.html을 열고 확인 줄의 제목·소제목·목록·굵게·링크 기대 개수를 기록해.
2. 페이지의 [본문 복사] 버튼을 클릭하고 복사 상태를 확인해.
3. 대상 편집기의 본문 칸을 클릭하고 키보드 Ctrl+V를 눌러.
4. 원본 HTML 페이지로 돌아가 [제목 복사]를 클릭하고 복사 상태를 확인해.
5. 편집기 제목 칸을 클릭하고 Ctrl+V를 눌러.

본문을 type/fill/텍스트 입력 도구로 타이핑하거나 HTML 소스를 입력하지 마.
서식 있는 클립보드는 페이지의 복사 버튼에서 만들어야 해.
Ctrl+A로 페이지 전체를 복사하면 안내 바까지 들어가므로 금지야.
복사 실패 또는 도구 기능 부족이면 중단하고 사람이 직접 붙여넣도록 알려 줘.
기존 제목이나 본문이 있으면 덮어쓰거나 중복 삽입하지 말고 중단해.

붙여넣은 편집기 본문에서 소제목(h2), 목록 항목(li, ul 개수가 아님),
굵게(strong/b), 링크(a)의 수를 확인 줄과 대조해.
제목 칸에는 제목 1개가 원문과 같고 본문에 제목이 중복되지 않는지도 확인해.
출처와 링크 주소, 문단 내용, 경험 슬롯도 원문과 대조해.
각 항목의 기대값/실제값을 보고해. 개수를 확인할 수 없거나 다르면 성공이라고
말하지 말고 임시저장도 하지 않은 채 중단해. 자동 재시도하지 마.

검증이 모두 맞으면 [임시저장]만 클릭하고 저장 완료 표시를 확인해.
완료 표시가 없으면 저장 성공이라고 말하지 마.
[발행]은 절대 클릭하지 마. 사실·출처·경험 슬롯 검수와 최종 발행은 사람이 해.
```

`확인` 줄의 목록은 목록 묶음이 아닌 항목 수입니다. 경험 슬롯의 굵게 표시도 굵게 개수에 포함합니다. 개수 일치는 서식 확인의 최소 조건이며 내용 검수나 게시 승인이 아닙니다.
