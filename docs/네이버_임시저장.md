# 네이버 블로그 임시저장

`frame write`가 만든 초안 한 개를 본인 네이버 블로그에 임시저장합니다.
발행 버튼은 사람이 직접 누릅니다. G3·G5의 `HUMAN_ONLY`는 그대로입니다.

## 처음 한 번: 설치와 직접 로그인

저장소 폴더에서 실행합니다. Playwright는 선택 의존성입니다.

```powershell
uv sync --extra naver
uv run --extra naver playwright install chromium
uv run --extra naver frame naver login
```

설치된 Chrome을 먼저 열고, 실행할 수 없으면 번들 Chromium을 사용합니다.
열린 창에서 사용자가 직접 로그인합니다. 프로그램은 비밀번호를 입력하거나 읽지 않습니다.
최대 5분 동안 `NID_AUT` 쿠키의 존재만 확인하고, `로그인 확인됨`을 출력한 뒤 창을 닫습니다.
창을 먼저 닫으면 로그인 확인을 중단합니다.

세션은 저장소 밖의 `~/.abbys/naver-profile`에 보관됩니다.
`ABBYS_NAVER_PROFILE` 환경변수로 다른 저장소 밖 폴더를 지정할 수 있습니다.
이 폴더는 공유하거나 Git에 넣지 마세요. 같은 프로필로 여러 명령을 동시에 실행하지 마세요.

## 초안 작성과 임시저장

`frame new`가 만든 작업폴더의 `profile.toml`에서 `[naver]` 아래 `blog_id`에 본인 ID를 입력합니다.
주소 전체나 비밀번호를 넣지 않습니다. 명령의 `--blog-id ID`가 이 설정보다 우선합니다.
초안 파일의 폴더부터 상위로 찾은 가장 가까운 `profile.toml`을 작업폴더 설정으로 사용합니다.

```powershell
uv run frame new 작업실
uv run frame write 작업실 --topic "생활 정보"
# 작업실/profile.toml의 [naver] blog_id 설정 후 실행
uv run --extra naver frame naver draft 작업실/초안/01_생활-정보.md
```

초안 파일 이름은 실제 생성된 이름으로 바꿉니다. 한 번에 초안 한 개만 처리하며 하루 몇 편 수준의 사용을 권장합니다.
로그인이 풀려 로그인 화면으로 이동하면 `frame naver login`을 먼저 실행하라는 안내와 종료코드 2를 반환합니다.

제목은 제목칸에, 소제목·문단·목록·굵게·HTTP(S) 링크와 출처는 본문에 넣습니다.
`### 점검표…`, `## 점검표…`, `**점검표 대조 결과**`, 독립 줄 `---`부터 문서 끝까지 제외합니다.
따라서 본문 중간 구분선으로 `---`를 쓰면 그 뒤도 제외됩니다.
프로필의 `experience_label`(기본 `내 경험`)로 시작하는 대괄호 슬롯은
**[내 경험 — 발행 전에 직접 채우세요]**로 바꾸고 경고합니다. 임시저장은 계속합니다.

기존 작성 글 팝업은 취소하고 새 초안을 입력합니다. 기존 작성 중인 글이 중요하면 먼저 직접 보관하세요.
본문은 HTML 클립보드로 붙여 넣고, 실패 후 본문이 비어 있으면 일반 텍스트로 대체합니다.
일반 텍스트 대체 시 서식은 사람이 다시 확인해야 합니다.
정확히 `저장`인 버튼만 누르고 2~3초 기다립니다. 저장 클릭은 서버 저장 성공을 보증하지 않으므로
브라우저에서 임시저장 상태를 직접 확인하세요.

## 사람이 확인하고 발행

기본 동작은 저장 후 창을 열어 둡니다. 내용·출처·사실을 확인하고 경험 슬롯을 직접 채운 뒤,
발행 여부를 사람이 결정합니다. 터미널에서 Enter를 누르면 브라우저가 닫힙니다.
`--close`를 붙이면 저장 후 바로 닫습니다.

## 실패했을 때

브라우저를 열기 전에 `초안.md` 옆에 `초안.naver.html`을 저장합니다.
브라우저 자동화가 실패해도 이 파일을 열어 제목과 본문을 따로 복사해 수동으로 붙여 넣을 수 있습니다.
같은 초안으로 재실행하면 HTML 사본은 갱신됩니다.

단계별 진행 상황을 출력하며 브라우저 작업 실패는 종료코드 1입니다.
로그인·필수 설정·선택 의존성 안내는 종료코드 2입니다.
가능하면 실패 화면을 현재 작업 경로의 `logs/naver_<시각>_<단계>.png`에 저장합니다.
창이 이미 닫혔거나 브라우저 실행 자체가 실패했다면 스크린샷을 만들 수 없습니다.
화면이 바뀌면 단계 이름과 스크린샷을 첨부해 Issue를 남겨 주세요.
첨부 전에 본문·계정 등 개인정보를 가리고, 프로필 폴더나 쿠키를 첨부하지 마세요.

구현은 [Playwright persistent context 문서](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch-persistent-context)를 따릅니다.
네이버 실제 로그인·저장은 자동 테스트 대상이 아닙니다. 테스트는 변환·설정·가짜 브라우저 경계와 발행 클릭 차단을 검증합니다.
