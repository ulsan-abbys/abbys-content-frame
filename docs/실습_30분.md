# 실습 30분

준비물은 Git, Python 3.11 이상, Windows PowerShell입니다.
Claude Code 또는 Codex를 사용할 수 있는 환경도 준비합니다.
`ulsan-avis`은 운영자가 알려준 GitHub 소유자 이름으로 바꿉니다.

| 순서 | 시간 | 남길 결과 |
|---|---|---|
| (1) clone + 설치 | 5분 | 가상환경과 설치 결과 |
| (2) 그래프·예시 점검 | 5분 | 명령 출력과 점검 결과 |
| (3) 내 분야 프로필 | 10분 | 프로필과 규칙팩 초안 |
| (4) 내 주제 초안·점검 | 10분 | 글 1편과 점검 결과 |

## (1) clone + 설치 — 5분

```powershell
git clone https://github.com/ulsan-avis/avis-content-frame
cd avis-content-frame
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

새로 받은 저장소에서 프로필을 복사합니다. 기존 파일이 있으면 보존합니다.

```powershell
if (-not (Test-Path config/profile.toml)) { Copy-Item config/profile.example.toml config/profile.toml }
```

이후 명령은 저장소 루트에서 실행합니다.
활성화 없이 가상환경의 Python을 직접 쓰는 방식입니다.
설치가 막히면 [AI에게 맡기기 (a)](AI에게_맡기기.md#a-설치)를 사용합니다.

## (2) frame graph / check 예시 — 5분

```powershell
.\.venv\Scripts\python.exe -m frame graph
.\.venv\Scripts\python.exe -m frame check examples/clinic/초안/01_겨울철-가려움-보습.md
```

`frame graph`, `frame check`와 같은 동작입니다.
G3·G5의 사람 전용 표시를 찾습니다. 초안의 측정값·오류·경고를 읽습니다.
`## 출처` 앞의 본문과 `[내 경험]` 같은 슬롯 위치를 확인합니다.
현재 clinic 예시는 923자로 기본 최소 1200자에 못 미칩니다. 분량 실패를 읽는 연습에 씁니다.
통과 결과도 보려면 `.\.venv\Scripts\python.exe -m frame check tests/fixtures/good.md`를 실행합니다.

## (3) profile.toml을 내 분야로 — 10분

[AI에게 맡기기 (b)](AI에게_맡기기.md#b-내-분야로-바꾸기)의 프롬프트를 붙여 넣습니다.
`○○`를 내 분야로 바꿉니다. 질문에 답하고 변경 내용을 비교합니다.

| 확인할 곳 | 확인할 내용 |
|---|---|
| `persona`, `style` | 분야·독자 목적·말투 |
| `draft` | 분량·소제목·출처·경험 슬롯 기준 |
| `rules.packs` | 새 영문 식별자의 규칙팩 연결 |
| 규칙의 `ref` | 확인하지 못한 법 조항은 `확인 필요` |

## (4) 내 주제로 초안 1편 + frame check — 10분

[AI에게 맡기기 (d)](AI에게_맡기기.md#d-초안--점검--고치기-루프)를 사용합니다.
주제를 하나 정하고 `drafts/01_내-주제.md`를 만듭니다.
경험 슬롯은 사람이 채웁니다. 출처 원문도 직접 확인합니다.

```powershell
.\.venv\Scripts\python.exe -m frame check drafts/01_내-주제.md
```

실패하면 최대 2회 수정합니다. 시간이 끝나거나 계속 실패하면 원인을 남깁니다.
통과해도 사실 검수와 게시 승인은 끝난 것이 아닙니다.
