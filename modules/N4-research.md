# N4 리서치·출처

## 하는 일

승인된 주제의 근거를 조사하고 출처의 내용과 접근 여부를 확인합니다.

## 입력

G1 승인 주제, 조사 질문

## 출력

주장과 출처의 대응표, 확인한 주소와 날짜

## 끝 기준

최소 출처 수를 충족하고 사람이 주장과 원문이 일치하는지 확인합니다.

## 실패 시 되돌아갈 곳

질문이 불명확하면 N3, 출처가 부족하면 N4로 돌아갑니다.

## 금지

주소가 열린다는 이유만으로 사실 검증 완료 선언, 출처 조작

## 지금 상태

`frame score`로 출처와 초안 주제의 관련성을 검사합니다. LLM이 판정하고, 지지·부분 지지 판정의 근거 문장이 실제 페이지에 있어야 인정합니다. 최소 출처 수에는 지지 판정만 포함하며 무관한 출처가 있으면 실패합니다. 주장별 원문 대응과 사실 확인은 여전히 사람이 확인하며, 조사 흐름은 연결이 필요합니다.
