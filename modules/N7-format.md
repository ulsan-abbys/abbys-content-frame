# N7 서식·이미지

## 하는 일

G2 검수를 마친 글을 읽기 쉬운 서식으로 정리하고 적합한 이미지를 준비합니다.

## 입력

G2 검수 글, 이미지 사용 권한

## 출력

게시용 서식, 이미지와 대체 텍스트

## 끝 기준

검수된 의미를 보존하고 이미지 권리·표현을 사람이 확인합니다.

## 실패 시 되돌아갈 곳

의미가 바뀌면 G2, 서식 문제는 N7로 돌아갑니다.

## 금지

무단 이미지 사용, 전후 사진을 통한 결과 과장
