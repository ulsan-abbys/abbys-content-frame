# V3 영상 점검

## 하는 일

영상 길이와 화면·음성·자막을 확인해 사람의 업로드 판단을 돕습니다.

## 입력

V2 영상, 목표 시간, 허용 오차

## 출력

길이 점검 결과와 사람의 재생 확인 기록

## 끝 기준

길이 기준을 확인하고 사람이 처음부터 끝까지 재생한 뒤 G5에서 업로드합니다.

## 실패 시 되돌아갈 곳

영상 출력 문제는 V2, 대본 문제는 V1로 돌아갑니다.

## 금지

업로드 클릭은 항상 사람입니다. 자동 게시·봇 탐지 우회 코드는 받지 않음

## 지금 상태

스텁 — 길이 검사 함수 구현됨, 실제 영상 길이 추출과 재생 검수 연결 필요
