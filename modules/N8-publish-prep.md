# N8 게시 준비

## 하는 일

제목·본문·출처·이미지를 모아 사람이 게시할 준비를 합니다.

## 입력

N7 서식과 이미지, G2 검수 기록

## 출력

사람이 붙여 넣고 확인할 게시 준비물

## 끝 기준

공개 전 미리보기와 출처를 확인하고 G3에서 사람이 게시 클릭을 수행합니다.

## 실패 시 되돌아갈 곳

표현·사실 문제는 G2, 서식 문제는 N7로 돌아갑니다.

## 금지

게시 클릭은 항상 사람입니다. 자동 게시·봇 탐지 우회 코드는 받지 않음
