# N8 게시 준비

## 하는 일

제목·본문·출처·이미지를 모아 Codex가 사용자 승인 범위 안에서 브라우저 작업을 수행할 준비를 합니다.

## 입력

N7 서식과 이미지, G2 검수 기록

## 출력

로컬 HTML과 .agent.txt 실행 지시서

## 끝 기준

게시 승인: 사람 (승인 후 Codex가 브라우저 도구로 실행·URL 확인). 기본은 임시저장이며 저장 상태와 제목·본문을 확인합니다. 공개 발행 완료는 실제 게시물 URL·제목·본문·출처 링크 확인으로 판정합니다.

## 실패 시 되돌아갈 곳

표현·사실 문제는 G2, 서식 문제는 N7로 돌아갑니다.

## 금지

CLI는 G3 승인을 스스로 생성하지 않습니다. 사용자 승인 없는 게시·무인 반복 게시·로그인 자동화·봇 탐지 우회 코드는 받지 않습니다. 로그인·캡차·보호조치에서는 중단하며 미작성 경험을 창작하지 않습니다.
