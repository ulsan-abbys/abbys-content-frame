# V2 렌더링

## 하는 일

검수된 대본과 로컬 소재로 세로 영상을 렌더링합니다.

## 입력

G4 검수 대본, MPT_DIR, 로컬 소재, 출력 폴더

## 출력

생성된 영상 경로

## 끝 기준

외부 도구가 성공하고 영상 결과 경로를 얻습니다. 영상 자체는 V3에서 확인합니다.

## 실패 시 되돌아갈 곳

외부 도구 설정은 V2, 발음·대본 문제는 V1로 돌아갑니다.

## 금지

권리 없는 소재 사용, 렌더링 성공을 게시 승인으로 간주
