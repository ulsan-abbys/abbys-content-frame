# N2 검색 수요

## 하는 일

이슈와 연관된 검색 수요를 확인하고 의미를 설명합니다.

## 입력

N1 이슈 목록, 지역, 관심 키워드

## 출력

기간·단위·출처를 포함한 수요 근거

## 끝 기준

상대 지수와 실제 검색량을 구분하고 표본의 한계를 명시합니다.

## 실패 시 되돌아갈 곳

근거가 부족하면 N1로 돌아갑니다.

## 금지

상대 지수를 검색 횟수로 표시하기, 검색 수요만으로 의료 수요 단정
