# N2 검색 수요

## 하는 일

이슈와 연관된 검색 수요를 확인하고 의미를 설명합니다.

## 입력

N1 이슈 목록, 지역, 관심 키워드

## 출력

기간·단위·출처를 포함한 수요 근거

## 끝 기준

상대 지수와 실제 검색량을 구분하고 표본의 한계를 명시합니다.

## 실패 시 되돌아갈 곳

근거가 부족하면 N1로 돌아갑니다.

## 금지

상대 지수를 검색 횟수로 표시하기, 검색 수요만으로 의료 수요 단정

## 지금 상태

구현됨 — `frame research`가 네이버 데이터랩에서 최근 12주 주간 상대지수를 조회합니다. 씨앗 검색어는 최대 5개이며 키 미설정·명시적 `--skip N2`는 skipped입니다. 401/024는 앱 권한과 Client ID 확인 안내를 남깁니다. `tests/test_research.py`에서 200·401/024·키 비노출을 오프라인 검증합니다.
