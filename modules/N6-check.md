# N6 기계 점검

## 하는 일

본문 분량·소제목·출처·경험 슬롯과 규칙 팩을 검사합니다.

## 입력

마크다운 초안, DraftSpec, RulePack 목록

## 출력

통과 여부, 지표, 줄 번호가 있는 발견 사항

## 끝 기준

오류가 없고 모든 지표가 기준을 만족하면 G2에 전달합니다. 경고는 사람이 확인합니다.

## 실패 시 되돌아갈 곳

실패하면 N5로 돌아갑니다. 설계도상 반복 상한은 2회이며 현재 CLI는 반복을 자동 실행하지 않습니다.

## 금지

검사 통과를 의료·법률 판단이나 사실 검증 완료로 표시
